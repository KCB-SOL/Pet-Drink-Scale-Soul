# Pet Drink: Scale & Soul — v1.2.0

Trò chơi nuôi thú ảo gắn với công việc vận hành quán đồ uống. Bản trải nghiệm dành cho cộng đồng ngành F&B.

- **Độ tuổi:** 12+
- **Chơi:** mở đường dẫn trang game bằng Safari hoặc Chrome. Trên iPhone, iPad: Chia sẻ → Thêm vào màn hình chính.
- **Key:** máy mới cần key do người phát hành cấp.
- **Dữ liệu:** lưu trên chính thiết bị của bạn, không gửi đi đâu.
- **Sự kiện:** tự đến khi mở game có mạng.
- **Không nạp tiền, không quảng cáo.**
